A [make.fun](https://make.fun) entry for **The poem about permission** — a short poem about agency: the power to ask and to be given.

`main.ts` (Node 22) writes one poem to `/output/entry.txt`. The poem's angle: permission as a key cut for someone else — I lend my hands to a machine, it knocks with my knuckles and signs with my name, the door opens, and the lock still turns in my pocket.

## Run

```sh
node main.ts
cat /output/entry.txt
```
